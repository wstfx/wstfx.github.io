并行更新约定 / Parallel update boundaries — 2026-10-03

当前允许 Work 内容与 UI 和首页插画同时开发。
- Work agent：work.html、work/ 下的项目页面、content/work-intro.html、项目内容源，及 Work 专用 CSS/JS/图片目录。可以新建 assets/css/work-ui.css 和 assets/js/work-ui.js；选择器限定在 Work 页面内。
- 首页视觉 agent：index.html、content/home-story.html、assets/art/、assets/css/story.css、assets/js/story.js、插画规范与制作脚本。
- 共享的 assets/css/portfolio.css、全站导航和 tools/build_site.py 同一时间只由一位整合者修改。本轮构建脚本由首页视觉 agent 维护；Work 页面需要新的构建入口时先约定接口。
- 可以只生成指定页面：python3 tools/build_site.py --only index.html visual-system.html illustration-direction.html。该命令不会写入 Work/About 页面。

- 共用 checkout 时，不切换分支、不 reset/stash 对方改动、不 git add .。只提交自己明确负责的文件；推送同一分支时串行进行。独立 worktree 可减少冲突，但共享文件仍需由一人整合。
